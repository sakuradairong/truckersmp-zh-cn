# 独立悬浮面板完整开发方案

日期：2026-11-03。实施分支：`feat/independent-panel`。产品名：Truck Companion Panel，首版 0.1.0。

## 交付范围

交付独立 Windows x64 EXE、纯 SCS 采集 DLL、单独放置的 SCS + 官方 TMP SDK 采集 DLL、可回退安装脚本、使用说明和源码。默认不安装或加载 TMP SDK 版。两个采集版本使用相同文件名，选择其一，不能同时安装。

首版实现：悬浮窗、中文界面、驾驶穿透/编辑模式、显示与模式热键、置顶、透明度、位置保存；附近玩家搜索、距离/速度/延迟排序、关注、工作人员/同 VTC 筛选；本车速度/油量/档位/导航与当前任务；个人资料/VTC/服务器状态；数据来源和过期状态。

公交扩展、聊天、车辆头顶文字、TMP 原生页面或配置修改不属于首版。独占全屏不保证显示，目标为窗口化/无边框。旧插件、公开 Release 和工单不在本次自动修改范围。

## 技术边界

新目标只编译 `panel/` 内源码，第三方依赖仅官方 TMP SDK、SCS SDK、PicoJSON。不会编入旧 `plugin.cpp`、`panel.h`、MinHook、指令解码器、RVA 或资源格式解析器。绘图采用自己的 HWND、Direct2D DC render target、DirectWrite 和 UpdateLayeredWindow。

TMP 采集只通过公开 Session/模块接口。`OnPostRender` 仅做限频采样，不获取游戏渲染设备，不绘图。`OnUpdate` 不用于 getter 采样。官方 SDK 是公开扩展机制；这不代表工单已单独批准本项目或旁车速度的外部展示，SDK 包保持可选且不自动部署。已有未发送确认草稿继续保留。

## 模块与文件

| 模块 | 文件 | 责任 |
| --- | --- | --- |
| 协议 | `protocol.h` | 固定宽度只读快照、长度/版本/来源/会话/时间戳、有效位 |
| 通信 | `transport.h/.cpp` | 本用户命名管道、禁止远程、核对服务器 PID、有界 I/O |
| 采集 | `collector.cpp/.def` | SCS 通道/事件；可选 TMP Session、范围事件、限量采样；无网络请求 |
| 公开 API | `public_api.h/.cpp` | HTTPS、JSON、限频缓存、失败退避、VTC 和服务器 |
| 配置 | `settings.h/.cpp` | 只写本面板的 LocalAppData，原子保存关注列表与窗口偏好 |
| 窗口 | `main.cpp`、`canvas.h`、`dialogs.h` | 独立绘制、DPI、热键、命中测试、原生输入框、交互、状态与筛选 |
| 客户端 | `data_client.h` | 后台发现游戏进程、读取快照、重连；不调用 SDK |
| 构建 | `build.ps1` | 只编译/链接 EXE 和两个 DLL，不启动程序、不执行测试/校验 |
| 安装 | `install.ps1` | 明确游戏目录、退出保护、备份和回退；旧插件需显式迁移开关 |
| 打包 | `package.ps1` | 默认 SCS ZIP 与单独的 TMP SDK 附加 ZIP；不执行程序或安装 |

## 协议与生命周期

命名管道按游戏 PID 命名，消息只有 Query；不存在通知、写配置、输入、挂钩或渲染命令。DACL 限制当前用户与 SYSTEM，拒绝远程管道连接。面板核对操作系统报告的管道服务器 PID；读取端限制消息大小，检查魔数、版本、枚举、长度、浮点数和字符串终止符。

快照保留编译能力、运行状态、SCS/TMP 时间戳、会话号、账号/服务器 ID、本车遥测及最多 256 名玩家。TMP ID/SteamID 不经浮点数存储。空值用有效位表达，不能把失败当作 0 km/h。SDK 数据超过 3 秒或失去连接时不作为当前列表展示，单个玩家的更新年龄也单独判断。

SCS 与 TMP 初始化可先后到达，各自持有采集运行时引用；卸载一方不能终止另一方。TMP 断线/切服清空玩家和会话状态。范围离开事件只删除本机加载记录，不解释成退出服务器。SDK 回调只复制数据，使用非阻塞发布；工作线程不调用 SDK。

初始化用一次 `GetAllPlayers()` 建立成员；流入/流出事件维护成员。限频采样使用固定批量，超出容量明确报告，不每帧扫描所有玩家。新会话重置旧数据；Reload 时销毁 Session 注销全部回调。

采样池上限 512 人，100ms 读取最多 32 人；超出者只保留有界的官方句柄等待进入采样池，流出时删除，空位出现后逐步补入。输出按已采样距离排序最多 256 人。在拥堵区域不声称输出覆盖所有范围内玩家。首次快照失败最多五秒重试一次，成功后停止轮询快照。

## 网络与隐私

公开 API 只使用固定 HTTPS 主机 `api.truckersmp.com`。禁用跨站重定向，限制响应长度，处理 HTTP 失败及 API 的 `error` 字段。只请求用户选择的账号或面板需要展示/筛选的已加载玩家账号；VTC 查询为缓存数据，不能冒充即时状态。

默认单个工作线程，玩家查询至少间隔 3 秒，成功资料缓存 15 分钟，失败退避，429 至少等待一分钟并处理 Retry-After。服务器列表按一分钟更新。无 API 密钥、聊天收集、账号登录或上传自己的遥测功能。

## 界面与交互

默认显示本车状态及“附近（已加载）”列表，提供本车/资料页。编辑模式允许点击、搜索、关注、拖动和设置；驾驶模式使用 layered/transparent/no-activate 组合并处理命中测试。热键默认 Ctrl+Shift+V 显示/隐藏，Ctrl+Shift+E 切换模式；冲突可在设置中修改。

窗口位置/DPI 变化后保留可访问区域。可跟随游戏前台自动隐藏，编辑时可留在桌面。所有列表缺失状态、连接状态、API 查询状态均可见。设置页使用原生 EDIT 控件支持中文 IME；不读取 TMP 键盘状态或拦截其输入。

## 实施顺序与完成标准

1. 固定协议、配置、通信接口，创建独立构建目标。
2. 实现采集生命周期和两种构建变体，加入公开 API 工作者。
3. 实现悬浮窗、中文展示、交互和状态边界。
4. 静态阅读、编译修复、生成可用目录及 ZIP、写使用/回退说明。

用户明确禁止烟测、SHA 校验和测试。本轮不会执行测试、SHA 命令、启动新 EXE、加载新 DLL 或启动游戏；不通过旧构建脚本间接运行这些步骤。完成标准为方案与源码齐全、独立编译成功、交付文件生成。实际显示、点击穿透、热键冲突、IPC 重连、SDK 生命周期、FPS 和全屏表现均保留为未执行验收项，不能称为已验证。

## 迁移与回退

新采集模块名称 `PanelDataBridge.dll`，与旧插件不同。安装脚本仅在用户运行时操作；若旧 `TmpNativeSpeedBridge.dll` 或 `TmpSettingsZh.dll` 仍活动，默认停止并解释，显式迁移选项会将它们移动到带时间戳的备份目录。新模块覆盖前保留旧副本及记录。新界面只读游戏数据，卸载只需关闭面板并在游戏退出后移走新 DLL。

本轮不自动部署到真实游戏目录，不发布版本，不发送工单。后续允许实机验收后，再决定默认启用 SDK 版与对外分发范围。
